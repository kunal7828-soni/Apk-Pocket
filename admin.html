📋 How to Add a New App

  1. Upload your APK file to the apks/ folder in your GitHub repo
  2. Upload the app icon to images/icons/ folder
  3. Optionally upload screenshots to images/screenshots/
  4. Fill in the form below
  5. Click "Generate JSON Entry"
  6. Copy the generated text
  7. Open data/apps.json on GitHub → Edit → Paste inside the [ ] array
  8. Commit the change → Done! App appears on site in ~1 minute
